# Datasheets – Smart Farm IoT Hardware

Este diretório deve armazenar os datasheets oficiais dos componentes críticos:

- ESP32-S3-WROOM-1-N8R8
- SHT31 (Sensirion)
- BME280 (Bosch)
- Sensor de solo capacitivo
- Regulador RECOM R-78E3.3-1.0

Quando possível, salve os PDFs com nomes padronizados, por exemplo:

- `esp32-s3-wroom-datasheet.pdf`
- `sht31-datasheet.pdf`
- `bme280-datasheet.pdf`
- `soil-sensor-capacitive.pdf`
- `r78e3.3-datasheet.pdf`
