# Smart Farm IoT — Hardware v1 (CELUS)

Esta pasta contém os arquivos exportados do CELUS Design Studio referentes ao protótipo **Hardware v1** do Smart Farm IoT System.

## Conteúdo

- `design-canvas.png`: captura do diagrama base construído no CELUS.
- `schematic.pdf` / `schematic.svg`: esquemático eletrônico gerado automaticamente.
- `bom.csv` / `bom.xlsx`: lista de materiais com fabricantes, part numbers e especificações.
- `pinout-esp32-s3-wroom.png`: mapa de pinos utilizado na Fase 3.
- `celus-project-info.md`: informações detalhadas do projeto dentro do CELUS.

## Objetivo do Hardware v1
Este hardware destina-se a:
- validar sensores ambientais (SHT31, BME280)
- validar sensores de solo (capacitivo)
- testar alimentação 5V → 3.3V
- integrar comunicação Wi-Fi/MQTT
- preparar dados reais para os testes do Mestrado

A versão v1 será substituída posteriormente por uma PCB dedicada (v2).
