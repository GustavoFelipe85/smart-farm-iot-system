# Smart Farm IoT — Hardware

Este diretório contém todos os arquivos, modelos e documentação relacionados ao desenvolvimento do hardware do projeto **Smart Farm IoT System**, incluindo esquemáticos, lista de materiais, pinout, arquivos exportados do CELUS Design Studio e documentação técnica de sensores.

## Estrutura

### `/hardware/celus-v1/`
Protótipo inicial do hardware, gerado com auxílio do CELUS Design Studio. Inclui:
- Schematic (PDF/SVG)
- Design Canvas
- Lista de materiais (BOM)
- Pinout do ESP32-S3
- Informações do projeto

### `/hardware/datasheets/`
Datasheets dos principais componentes utilizados:
- ESP32-S3-WROOM
- SHT31 (Sensirion)
- BME280 (Bosch)
- Sensor de Umidade do Solo (Capacitivo)
- Regulador R-78E3.3 (Recom Power)

### `/hardware/kicad/`
Planejado para versões futuras com PCB real em laboratório.

## Versão Atual
**Hardware v1 — ESP32-S3 + Sensores Ambientais + Sensor de Solo**

Esta versão será utilizada para:
- Processos de prototipagem
- Ensaios de laboratório
- Teste de sensores ambientais e de solo
- Construção da pipeline de dados real para o Mestrado
