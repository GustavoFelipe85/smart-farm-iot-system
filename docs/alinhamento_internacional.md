# Alinhamento Internacional e Sustentabilidade

## Contexto
O projeto Smart Farm IoT System foi concebido para atender não apenas
requisitos técnicos, mas também diretrizes internacionais relacionadas
à agricultura de precisão, uso eficiente da água e sustentabilidade ambiental.

## Instituições e Diretrizes de Referência

### FAO — Food and Agriculture Organization (ONU)
A FAO recomenda o uso de sensores, IoT e análise de dados para:
- gestão racional da irrigação
- redução do desperdício hídrico
- aumento da eficiência agrícola

Fonte:
https://www.fao.org/digital-agriculture
https://www.fao.org/land-water

### World Bank
O Banco Mundial apoia projetos de agricultura digital e monitoramento hídrico
baseados em dados como ferramenta de sustentabilidade.

Fonte:
https://www.worldbank.org/en/topic/water

### CGIAR
Rede global de pesquisa agrícola com foco em:
- agricultura de precisão
- segurança hídrica
- dados ambientais contínuos

Fonte:
https://www.cgiar.org/impact/areas/water/

## Contribuição do Projeto
O Smart Farm IoT System contribui diretamente para essas diretrizes ao:
- monitorar umidade do solo em tempo quase real
- registrar dados em séries temporais
- criar base para decisões de irrigação orientadas por dados
- preparar a automação futura com controle fechado

## Economia de Água e Uso Consciente
O sistema evita irrigação baseada apenas em calendário,
substituindo-a por decisões fundamentadas em dados ambientais reais.

## Perspectiva Científica
Este alinhamento reforça o potencial do projeto para:
- pesquisa aplicada
- experimentação controlada
- publicação científica
- evolução para dissertação de mestrado
